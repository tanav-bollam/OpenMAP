# Imbalance handling and uncertainty

Generated by `src/analyze_sweep.py`. Variants and the prior-correction strength `tau` were chosen on the **validation** split only; the test split was then read once for the selected and the original configuration.

## Setup

- MERT head variants (5): `base` = loss weights `inv_sqrt`, sampler `none`; `noweight` = loss weights `none`, sampler `none`; `inv` = loss weights `inv`, sampler `none`; `sampler_sqrt` = loss weights `none`, sampler `sqrt`; `sampler_inv` = loss weights `none`, sampler `inv`.
- 5 seeds per variant ([1, 2, 3, 4, 5]); the best epoch of each run is chosen by validation macro-F1.
- Post-hoc prior correction: predict argmax of `p / prior^tau`, tau in [0.0, 0.25, 0.5, 0.75, 1.0], prior = training class frequency.
- Selected on validation: MERT = `base` with tau = 0.0; CNN: tau = 0.0.
- 25 MERT configurations were compared on validation, so validation scores of the winner are optimistic.
